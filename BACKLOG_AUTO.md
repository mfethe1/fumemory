# BACKLOG_AUTO.md

Validated follow-up work from the fumemory autoresearch loop.

## Rules
- Add items here only after an experiment has evidence.
- Every item must include: owner, priority, evidence, and next action.
- If an experiment fails, log it in `autoresearch/ledger/experiments.jsonl` instead of adding it here.
- Close or remove stale items only when the evidence says the risk is gone.

## Template
```md
- [ ] AUTO-YYYYMMDD-XX — <title>
  - owner: <agent>
  - priority: P0|P1|P2
  - area: nats-reliability|contract-alignment|loop-quality
  - evidence: <test/doc/commit/report>
  - next action: <small reversible step>
```
